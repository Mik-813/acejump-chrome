AceJump for Chrome

Jump to any visible text, then select it with the keyboard.

Shortcut

Current shortcut: …

Chrome manages extension shortcuts at chrome://extensions/shortcuts. Clicking the toolbar icon also starts a jump.

How it works
  1. Press the shortcut. Type the text you want to jump to, then press Enter.
  2. Every visible match gets a label. Type the label to jump there (Backspace edits the query, Esc cancels).
  3. Caret mode starts at the match. Move with hjkl or the arrows, w/b by word, 0/$ to the line start/end. Press v to start selecting, V to select the line, o to swap ends, y to copy, Esc to leave.
  4. In visual mode, press s or the shortcut again to jump the other end of the selection to another match.

Custom CSS

Added after the theme inside the extension's shadow root, so it overrides the theme and the page can't interfere. Style the classes below or override the --aj-* variables on :host. The preview updates as you type.
